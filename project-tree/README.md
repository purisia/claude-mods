# project-tree

Claude Code mod. 현재 프로젝트 폴더를 대화 오른쪽 탭에 트리로 띄운다.

```
my-project 📂                        설정
/ 파일 이름 검색 · Enter                  ×
 ▾ data/ 📂
     dates.json
     new.csv                              +
     └ [ 열기 ]  [ 경로 복사 ]
 ▸ scripts/ 📂                            •
   README.md                              ~

─ 최근 작업 ────────────────────── 비우기
+ new.csv  data
  └ [ 파일 열기 ]  [ 폴더 열기 ]  [ 경로 복사 ]
~ README.md
```

- 폴더를 눌러 펼치고 접기, 폴더 이름 옆 📂로 탐색기에서 열기
- 파일을 누르면 [열기](연결된 프로그램으로 열기)·[경로 복사](절대 경로를 클립보드로)
- 파일 이름 검색 (입력 후 Enter)
- Claude가 만든 파일은 `+`(초록), 고친 파일은 `~`(노랑), 그런 파일을 품은 접힌 폴더엔 `•`
- 맨 아래 "최근 작업"에서 Claude가 만들고 고친 파일을 바로 열거나, 탐색기에서 보거나, 절대 경로 복사
- 탭이 열려 있는 동안 3초마다 펼친 폴더를 다시 읽어 밖에서 만든 파일도 보인다
- 목록을 드래그해도 클립보드로 복사되지 않는다

## 설치

```
/plugin marketplace add purisia/claude-mods
/plugin install project-tree@purisia
```

## 쓰는 법

마우스로 쓴다.

| 동작 | 방법 |
|---|---|
| 닫은 탭 다시 열기 | `/tree` |
| 최근 작업 개수 | `설정`에서 `[ − ]` `[ + ]` (1~30, 기본 8) |

## 참고

- Claude가 Write·Edit·NotebookEdit로 손댄 파일만 표시한다. 셸 명령으로 바꾼 파일은 목록에만 반영된다.
- 탐색기 열기는 Windows에서 PowerShell 도우미를 하나 띄워 두고 쓴다 (누르면 바로 열리게). macOS는 `open`, 리눅스는 `xdg-open`을 쓴다.
- 전체화면 모드에서 터미널이 110칸 이상이면 대화 옆에 붙고, 좁으면 프롬프트 위에 들어간다.
