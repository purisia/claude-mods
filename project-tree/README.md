# 📁 project-tree

Claude Code mod. 현재 프로젝트 폴더를 대화 오른쪽 탭에 트리로 띄운다.

- 폴더를 눌러 펼치고 접기, 폴더 이름 옆 📂로 탐색기에서 열기
- md·html·그림 파일은 누르면 "열까요?"를 묻고 연결된 프로그램으로 열기 (여는 확장자는 ⚙ 설정에서 바꾼다)
- 파일 이름 검색 (입력 후 Enter)
- Claude가 새 파일을 만들면 그 폴더까지 펼치고 ✨ 표시, 맨 아래 "방금 만든 파일"에서 탐색기로 바로 보기
- 탭이 열려 있는 동안 3초마다 펼친 폴더를 다시 읽어 밖에서 만든 파일도 보인다
- 목록을 드래그해도 클립보드로 복사되지 않는다

## 설치

```
/plugin marketplace add purisia/claude-mods
/plugin install project-tree@purisia
```

## 쓰는 법

| 동작 | 방법 |
|---|---|
| 탭 접기·펼치기 | 맨 위 `⇥ 접기`, 프롬프트 위 `◂ 펼치기`, 또는 `/tree` |
| 목록 키보드 조작 | 목록을 클릭한 뒤 `↑` `↓` `PgUp` `PgDn` `Home` `End`, `Enter` 누르기, `o` 폴더를 탐색기로 |
| 여는 파일 종류 바꾸기 | `⚙ 설정`에서 확장자를 누르면 빠지고, 입력칸에 `pdf, txt`처럼 넣으면 더해진다 |

## 참고

- 탐색기 열기는 Windows에서 PowerShell 도우미를 하나 띄워 두고 쓴다 (누르면 바로 열리게). macOS는 `open`, 리눅스는 `xdg-open`을 쓴다.
- 전체화면 모드에서 터미널이 110칸 이상이면 대화 옆에 붙고, 좁으면 프롬프트 위에 들어간다.
